# PAGE REPORT FORMAT (parallel rescue — one file per agent: <page-slug>.md)
Required sections: PAGE · WHAT WAS BROKEN (close-up list) · CHANGES (numbered, ≥5 visible)
· REFERENCES USED (exactly 3: name + what was borrowed — missing refs = failed run)
· FILES TOUCHED · GATES RUN + results · SCREENSHOTS (before/after, light+dark paths).
Do NOT edit CURRENT_STATE.md, TASTE_LOG.md, FEATURE_QUEUE.md, SITE_MAP.md, PHOTO_QUEUE.md
— the director merges those after all parallel agents finish.
